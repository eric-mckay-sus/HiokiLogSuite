
# Hioki Parser 

A solution for parsing Hioki device logs and converting natural-language search queries into SQL.

## Projects

- **HiokiParser**: Log parsing utilities
- **HiokiNL2SQL**: Blazor UI and query translation logic
- **HiokiNL2SQL.Tests**: Unit and integration tests

## Quick start

```bash
dotnet build
dotnet run --project HiokiNL2SQL\HiokiNL2SQL.csproj
dotnet test
```
