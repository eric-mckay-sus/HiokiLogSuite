
# Hioki Parser Mark1

A solution for parsing Hioki device logs and converting natural-language search queries into SQL.

## Projects

- **HiokiParserMark1**: Log parsing utilities
- **HiokiNL2SQLMark1**: Blazor UI and query translation logic
- **HiokiNL2SQL.Tests**: Unit and integration tests

## Quick start

```bash
dotnet build
dotnet run --project HiokiNL2SQLMark1\HiokiNL2SQLMark1.csproj
dotnet test
```
